# p2_data: dataset, features and baselines (P2)

Scripts and configuration that build the project's video dataset (data v1) on USC CARC. The data itself
isn't in git. Every file under `data/` is regenerated by these scripts.

| Path | What |
|---|---|
| `config/clip_sources.csv` | hand-curated sources: films, Xiph, UVG, Netflix (URL, licence, group, split) |
| `config/exclude_clips.csv` | clips the team decided to drop, with reasons |
| `config/cut_review_v1.csv` | human/Claude review verdicts that override the automatic cut rule |
| `scripts/select_clips.py` | builds `data/clip_candidates.csv` (curated sources + stratified YouTube UGC sample, splits by group) |
| `scripts/download_clips.py` | downloads only the frames each clip uses (run on a transfer node) |
| `scripts/decode_clips.py` + `jobs/decode_v1.sbatch` | decodes to 8-bit 4:2:0 y4m at a fixed size (default 320x180), one array task per clip |
| `scripts/cut_labels.py` | scene-cut signals, rules, review overrides -> `gops.csv` (stable / cut / gradual) |
| `scripts/frame_features.py` | per-frame features (SI/TI so far) |
| `scripts/joblog.sh` | ledger of sbatch submissions |
| `docs/clip-selection.md` | every rule and decision, with the evidence behind it |
| `docs/p2-plan.md`, `docs/p2-tracker.md` | the P2 plan and live status |

## Rebuilding data v1

Run from this directory. It needs ffmpeg: `module load ver/2506 gcc/14.3.0 ffmpeg/7.1.1`.

```bash
python3 scripts/select_clips.py                         # candidate list + splits
python3 scripts/download_clips.py                       # on hpc-transfer1; ~36 GB + PNGs for priority 1
python3 scripts/decode_clips.py --make-tasks            # prints the array size N
sbatch --array=0-<N-1>%20 jobs/decode_v1.sbatch
python3 scripts/decode_clips.py --merge                 # manifest.csv
python3 scripts/cut_labels.py --signals && python3 scripts/cut_labels.py --label
python3 scripts/frame_features.py --siti
```

Results land in `data/v1/320x180/`: `clips/`, `manifest.csv`, `gops.csv`, `cuts/` and `features/`.
